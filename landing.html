Privacidad

Tus capturas no salen de tu equipo.

Un pcap puede contener credenciales, hosts internos y datos de tus clientes. Por eso PcapAnalyzer se ejecuta en tu infraestructura, no en la nube de nadie.

  • El archivo se analiza y se borra al terminar. No se almacena.
  • La IA es opcional y recibe solo un resumen JSON, nunca los paquetes.
  • Usas tu propia clave de API — o el modo demo, sin clave alguna.
  • Sin telemetría, sin cuentas, sin dependencias externas para el análisis.

Dudas rápidas

Antes de comprar.

¿Necesito una clave de API para usarlo?

No es obligatoria. Sin clave, la app funciona con un modo demo que simula el diagnóstico a partir del propio análisis. Si quieres el diagnóstico con IA real, pones tu propia clave de Anthropic (el coste va a tu cuenta, ~0,05–0,10 € por diagnóstico).

¿Qué necesito para ejecutarlo?

Docker y Docker Compose. Un solo comando (docker compose up --build) levanta todo y abres localhost:8080. Incluye una guía de inicio paso a paso.

¿Mis capturas son privadas?

Sí. Todo el análisis ocurre en tu máquina y el archivo se descarta al terminar. Solo si activas la IA se envía un resumen JSON de métricas — nunca los paquetes ni el pcap.

¿Recibo actualizaciones?

La descarga incluye el código completo, así que es tuyo para ejecutar y adaptar. Las mejoras futuras se publican como nuevas versiones.
